## 首轮建议（历史记录，当前事项以接入清单为准）

当前飞猪正式密钥已配置并成功查询，样例酒店已借助现有Chrome登录状态核验，无需再次申请密钥或扫码。飞猪为主；携程登录不作为本轮必要事项。最新申请见 [接入清单](provider-onboarding.md)。

1. 手动解锁 Mac，在已打开的 Chrome 携程登录页完成登录；密码、短信验证码不需要发到聊天里。
2. 在飞猪 AI 开放平台进入“获取 API Key”，完成账号登录和申请。密钥通过本机环境变量 / 安全凭证配置交给程序，不能提交到 Git、文档或截图中。
3. 若已有 Booking.com 或 Agoda 商业合作账号，可配置该账号正式颁发的凭证；若没有，需要合作申请，不能承诺即时获批。
4. 真实下单前另行明确城市、日期、入住人信息、商家、含税总预算及可接受取消条款。当前请求仅授权接入测试，没有授权真实消费或取消已有订单。

## 实现仍需完成的部分

真实搜索读取成功不代表现有控制台已完成整合。需要真实平台适配器，将来源、报价时间、人数、房型、餐食、税费、取消条款和评论原文映射到现有规则。缺失的关键事实应阻断自动成交。真实退款须以商家 / 支付渠道的到账状态为准，不能使用仿真钱包余额和退款时钟替代。
